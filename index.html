添加基金

开启后从下一个定投日开始，净值公布后自动按当日净值记一笔买入

买入

按当前最新确认净值即时记账；实际场外申赎按当日收盘净值 T+1 确认，可能有微小差异。卖出会计入「已实现盈亏」。

推送设置

前往 sct.ftqq.com 用微信扫码登录，复制 SendKey 填入并保存。
之后每当本设备在净值公布后首次生成当日战报，会自动推送一条微信消息。
原理说明：网站被打开时若发现今天还没生成战报，就拉净值生成并推送——所以电脑定时任务或你打开网站的任意一次访问，都会触发微信提醒。

批量导入持仓

每行一只基金，用空格分隔：
基金代码 份额 成本单价
成本单价可省略（省略后不计累计收益）。
示例：
005827 1000 1.85
161725 2000 0.95

GitHub 持仓同步

配置后，你在本页增删改持仓会自动提交到仓库的 holdings.json，每日推送随之更新，无需去 GitHub 手动修改。
Token 只需创建一次：GitHub → Settings → Developer settings → Fine-grained tokens → 勾选该仓库的 Contents: Read and write 权限。
